# Toolkit artwork sources

The two profile strips use existing brand artwork from [SVG Logos](https://github.com/gilbarbara/logos), distributed through [Iconify](https://github.com/iconify/icon-sets), plus the scikit-learn mark from [Simple Icons](https://github.com/simple-icons/simple-icons). These collections distribute their artwork under CC0; brand names and logos remain the property of their respective owners and do not imply endorsement.

Tile layout, labels and warm neutral backgrounds are presentation wrappers, not replacements for the original logos. The SVG strips are self-contained: viewing the profile does not depend on a third-party icon API.

The optional build script is `scripts/build-profile-icons.py`. It refuses to overwrite existing strips.
