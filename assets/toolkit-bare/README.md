# Bare toolkit icons

Development, data and operating-system PNGs come from [marwin1991/profile-technology-icons](https://github.com/marwin1991/profile-technology-icons), pinned to commit `376c2f9b0ff0ebfcef3f9f5ca252e12c46b17057`.

AI, Cloud Run, Power BI and Tableau SVGs use [SVG Logos](https://github.com/gilbarbara/logos) via Iconify. The scikit-learn SVG uses [Simple Icons](https://github.com/simple-icons/simple-icons). These are the same verified artworks used in the previous strips, without the added card backgrounds or labels. SVG Logos and Simple Icons distribute artwork under CC0; brand names and marks belong to their respective owners and do not imply endorsement.

The profile uses two equal-width rows of fourteen individually labelled images. Each image occupies 7.14% of the row, using a normalized 112-pixel transparent canvas cropped from the approved artwork. This preserves the full-width layout while restoring a separate hover title for every logo. Light/dark variants remain available for monochrome marks. There are no card backgrounds or visible captions. Earlier source artwork and composite strips are retained.
